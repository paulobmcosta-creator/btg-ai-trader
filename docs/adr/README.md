# Architectural Decision Records

ADRs registram decisões relevantes, alternativas, consequências e estado de aprovação. Use numeração sequencial (`0001`, `0002`, ...). Uma decisão aprovada não deve ser reescrita silenciosamente; mudanças posteriores recebem novo ADR que substitui o anterior.

Estados sugeridos: `Proposta`, `Aceita`, `Rejeitada`, `Substituída`.
