# Documentação

Esta pasta concentra a memória técnica duradoura do projeto.

- `architecture/`: contexto, componentes planejados, limites e decisões em aberto;
- `adr/`: decisões arquiteturais com motivação e consequências;
- `protocols/`: procedimentos verificáveis de segurança, dados e validação;
- `sprints/`: objetivos, critérios de aceite, evidências e pendências.

Documentos descrevem intenção e controles; não autorizam execução financeira.
